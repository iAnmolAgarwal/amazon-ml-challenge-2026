# 3. Pipeline as built
**Normalization (per record, several views kept side by side):** NFKC + lowercase; Latin diacritics folded, Indic vowel signs kept; tokens of [0-9a-z, Latin-extended, Indic blocks]; "M/s" and honorific prefixes removed; "formerly/previously known as, dba, aka, trading as" split into an alternate name; website form parsed (TLD stripped, glued legal suffix removed); split legal words re-joined ("li mited", "l l c"); digit-for-letter undone inside mixed tokens; legal words (pvt, ltd, limited, llc, inc, corp, co [not first token], sarl, sas, eurl, gmbh, ...) removed as tokens. Views: core name, space-free join, sorted-token join, initials, alternate name, normalized address tokens (abbreviations expanded: rd->road, st->street, av->avenue, bd->boulevard, ...), house number (templates first; suite/apt/unit/PO box numbers skipped), first street token after the house number, postal code (last 5-6 digit number not equal to the house number), all numbers, and a combined text = core name + address tokens.

**Blocking, per country:** (1) word view: TF-IDF (sublinear) over hashed word 1-2 grams of the combined text (whitespace tokenizer so Indic words and single characters survive), exact top-40 cosine neighbours per S1 via sparse_dot_topn with the pool split into 125k-row chunks and merged (measured 8,083 queries/s per 1M pool rows on 8 cores); (2) exact-key joins: house+street, space-free name, sorted-token name, name+house, initials+house (acronyms), alternate name vs S1 name; key values with more than 50 rows on either side are skipped (not truncated). Union; word cosine computed for key-only pairs.
Measured on 20k S1 per country against the full train pool: pair recall US 0.985 / India 0.950; oracle macro F0.5 US 0.9952 / India 0.9820 (0.9886 overall); entities with every true match missed: US 0.10% / India 0.51%; 45.6 candidates per S1 (p99 85).

**Features (41 per pair):** word cosine; ranks and gaps from both sides (S1's rank of the candidate, pool record's rank of the S1), candidate count per S1, rival count per pool record; six key flags and their sum; name: rapidfuzz ratio, token_set, token_sort, partial, Jaro-Winkler on core name, ratio and partial on space-free join, join equality, acronym match (S1 initials = pool join), alternate-name token_set; address: token_set, ratio, partial; house equal / house prefix (634 vs 6345) / missing, street equal, postal equal / postal conflict, number Jaccard; S3 flag, website flag, empty-address flags, token counts, non-Latin-script flags for pool name and address. No ids, row positions or country used as features.

**Model:** LightGBM binary (lr 0.05, 127 leaves, min_data_in_leaf 200, feature/bagging fraction 0.8, 600 rounds, no class weighting), trained on the candidates of a 20% sample of training-fold entities.

**Decision rule:** (a) each pool record kept only for the S1 with its highest probability (ties to lowest index); (b) per S1, sort kept probabilities p1>=p2>=..., E[T] = sum(p); choose k maximizing 5*sum(p_1..p_k)/(E[T]+4k) for k>=1, versus k=0 scoring prod(1-p); keep the top k.

**CV:** 5 folds over S1 entities, stratified by country x match count (verified identical composition). Out-of-fold probabilities for every training pair; the decision rule runs once on the full out-of-fold graph so rival S1 entities compete as on test. Macro F0.5 per fold, test-weighted by country (US 0.38, India 0.47), oracle, by match count. Acceptance of changes: mean per-fold paired difference > 2x its standard error and positive in at least 4 of 5 folds.

**France:** nothing France-specific beyond generic normalization (accents folded, a few French street abbreviations, French legal forms removed). Country is an open set; blocking runs per country label; no country feature.

**Independent code review (done):** no leakage found; topk, decide, metric verified against brute force; 12 issues fixed (postal vs house number, M/s, formerly-known-as, split legal words, over-stripping join keys, suite numbers, tokenizer dropping Devanagari, sample scoring, tie determinism, fold alignment).
