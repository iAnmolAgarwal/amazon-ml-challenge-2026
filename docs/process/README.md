# How the 72 hours were run

These files ran the challenge and are kept as they were written at the time, so paths inside them point to the old layout (for example `prompts/` at the repo root).

- `CLAUDE.md`, `RUNBOOK.md`: rules and procedure for the lead and worker Claude Code sessions.
- `prompts/`: the lead, worker and Codex audit prompts.
- `orchestration/`: assignments and checkpoints written by the lead session.
- `reviews/`: the prompt and feedback for each stage's outside review, plus the audits.
- `STATUS.md`, `TASKS.md`: the live status board and task list during the challenge.
- `LATEST_SUBMISSION.md`, `ER_Handoff_0.989022_Approach.md`: handoff notes after each scored upload.
- `aws-setup.md`, `research_brief.md`, `archive/`: infrastructure notes, the research brief and older approach write-ups.
