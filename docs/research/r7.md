# r7: graph structure among pool records (decoy-robust)

Status: exp1/exp3 (2.5) and stage-3 under the decoy conditions (2.6) measured. The hed test guard was never run.

## 1. Verdict
- **Graph angle: negative (measured).**
  - Graph arms gain +0.0033 in normal CV but collapse under decoy clusters: clone_dep -0.037 / -0.041, 0/5 folds (2.5).
  - Test shows exactly such clusters, label-free (2.4). Do not ship pool-pool coherence, support, clustering or component features.
- **Pivot: pair-level house-edit features (hed), judging each pair against the S1 alone.**
  - 10% sample: +0.00321 normal (5/5; US +0.0041, India +0.0018).
  - +0.00370 with decoys doubled (5/5): the gain grows with decoy density.
  - r9's hd/hd_D encode the same signature (house delta in {1..21}), so p59 already contains most of it.
  - Expected LB (guessed): +0.003 to +0.004 over 006 if shipped alone; not additive with r9's house features.
- **Stage-3 p5/p59 (2.6): the gain holds and grows with decoy density.** p59 - p006 is +0.01014 normal and +0.01246 with doubled decoys (5/5; US +0.0114, India +0.0141). The house-conflict guard will rise by design: US 0.071 -> 0.084 on train with 57% fewer false positives.

## 2. Evidence

### 2.1 What the decoys are (train, labels; 10% sample, 006 OOF decision) - measured
- Emitted false positives: 4,375 are orphans (pool records owned by no S1) and 474 belong to another S1. Orphans are 90% of false positives.
- House-conflict share of emitted pairs: orphan false positives US 51% / India 35%; true positives 6.8% / 16.0%.
- Decoys are near-copies of the S1's entity with one perturbed field (house shifted, name token mutated, suffix swapped). Sometimes they copy a true record's address typos exactly.
- In train, decoys are singletons. Orphans with p006 > 0.05 per S1: 469k S1 have 1, 16k have 2, 0.7k have 3 or more.
- Missed gold pairs (45,851 of 764,274): low probability 16.6k, not retrieved 14.8k, lost to a rival 8.8k, top-k cut 5.6k.

### 2.2 What differs on test (label-free) - measured
- Test's ~1.1 extra pool records per S1 fall mostly in the 0.001-0.9 best-probability range.
  - US: 0.01-0.1 +0.44, 0.1-0.3 +0.12, 0.3-0.5 +0.047, 0.5-0.7 +0.026.
  - The unretrieved and < 0.001 buckets add only +0.10 (US) / +0.32 (India).
  - Implied orphan rate in 0.1-0.9: 2.3-2.8x train.
- So the excess is near-duplicate decoys of existing S1, not orphan clusters from missing S1.
- US house-conflict candidates per S1 roughly double (0.05-0.3: 0.179 -> 0.403; 0.3-0.6: 0.056 -> 0.118); house-equal ones barely move.
- Script: `eda3.py`, `eda4.py`.

### 2.3 Decoy signature: small house edits - measured
House-conflict pairs with p006 > 0.05, train precision by edit kind:

| edit kind | US | India | note |
|---|---|---|---|
| 1 digit substituted | 0.40 | 0.73 | US orphans 10,025 |
| edit distance 2 | 0.23 | 0.73 | US orphans 13,128 |
| edit distance >= 3 (e.g. 730 vs 335) | 0.80 | 0.91 | |
| substring (1320 vs 132) | 0.92 | 0.88 | |

- 006 has house_eq, house_prefix and num_jacc, which are 0 for both 634/637 and 730/335.
- Edit distance alone mixes the two (730 vs 335 has distance 2), hence the numeric-difference features h_nabs / h_nrel in 2.5.
- Test / train per S1, US: 1-substitution and edit-distance-2 rise 2.3-2.6x in the 0.05-0.6 bands. Edit distance >= 3 and substrings rise 1.1-1.6x.
- Implied test precision (own density fixed) in the 0.6-0.9 band:
  - US: 1-substitution 0.40 (train 0.70), edit distance 2 0.23 (train 0.54);
  - India: 0.56 (0.79) and 0.41 (0.65).
- Above 0.9 (US): 0.87 (0.97) and 0.82 (0.95).
- Derived upper bound, if every pair above 0.6 were emitted: small-edit false positives per US S1 are 0.0098 on train and 0.0375 on test. At ~0.19 F0.5 each, that is ~0.0018 of US CV loss and ~0.007 of US test loss. Rejecting them is worth ~4x more on test than on CV.
- Script: `eda8.py`.

### 2.4 Test decoys cluster; train decoys do not - measured (the leader's hypothesis holds)
- Shared house deviation = a near candidate (p006 > 0.05) whose house differs from the S1's and equals another near candidate's.
- Train: 96% of these are true matches (the entity's second address): US 22,968 own vs 882 orphans; India 35,884 vs 508.
- Per S1, train -> test:

| band | US | India |
|---|---|---|
| 0.05-0.3 | 0.019 -> 0.184 (9.6x) | 0.013 -> 0.085 (6.6x) |
| 0.3-0.6 | 0.017 -> 0.070 (4.3x) | 0.015 -> 0.036 (2.4x) |
| 0.6-0.9 | 0.024 -> 0.045 (1.9x) | 0.034 -> 0.045 (1.3x) |
| > 0.9 | 0.121 -> 0.133 | 0.353 -> 0.370 |

- Candidates with a unique deviating name token rise only ~2x.
- House support (another p > 0.5 candidate with the same house): train orphans with a conflict 1% (US) / 4% (India) vs true matches 57% / 71%. The implied support rate of test's extra decoys is ~15%.
- A model given sibling agreement, including a "unique deviation" flag (0 means shared), promotes these clusters on test. Train has too few decoy clusters to learn the reverse sign.
- Script: `eda5.py`, `eda4.py`.

### 2.5 Paired experiments (in-sample 5-fold LightGBM, same folds, 300 rounds at lr 0.1 for every arm) - measured
Arms:
- hed = base + h_lev, h_1sub, h_sub, h_ldiff, h_nabs, h_nrel (pair-level).
- gneg = base + unique-deviation / twin flags (pool-pool).
- gall = gneg + support and shared-deviation counts.

Conditions (models trained on normal data only):
- clone_ind: each near orphan (p006 > 0.05, owned by no S1) duplicated once with its features.
- clone_dep: the same, but graph features recomputed, so the clone and the orphan form a decoy cluster.
- removal: 19% of all S1 removed; pool-side features and the rival recomputed.

Quick subset (44k S1), diff vs base (all SE <= 0.0005):

| condition | hed | gneg | gall |
|---|---|---|---|
| normal | +0.00342 (5/5) | +0.00335 (5/5) | +0.00331 (5/5) |
| clone_ind | +0.00417 (5/5) | +0.00427 (5/5) | +0.00455 (5/5) |
| clone_dep | +0.00417 (5/5) | **-0.03740 (0/5)** | **-0.04109 (0/5)** |
| removal | +0.00371 (5/5) | +0.00326 (5/5) | +0.00330 (5/5) |

- US false positives in clone_dep: base 1,367, hed 1,076, gneg 9,308, gall 9,461. The graph arms emit the cloned clusters.
- Full 10% sample (220k S1), hed vs base:
  - normal +0.00321 (SE 0.00010, 5/5; US +0.00414, India +0.00181);
  - clone_ind +0.00370 (SE 0.00011, 5/5; US +0.00483, India +0.00202);
  - decoy-weighted +0.00406 / +0.00497.
  - US false positives: 2,689 -> 2,340 (normal) and 5,625 -> 4,655 (clone_ind).
- Caveat: hed raises the house-conflict share of emitted pairs (US 0.070 -> 0.079) because it recovers true second-address matches. For hed, the test house-conflict guard is not a decoy measure; use the small-edit share. Test guard: NOT RUN (killed at 6 GB, never relaunched).

### 2.6 Stage-3 corrections under the decoy conditions (p006 vs p5 vs p59, v6_probs; 220k S1) - measured
Protocol:
- r5 and r9 features are pair-level (S1 vs pool; no sibling or other-S1 inputs), so clones reuse each row's p006/p5/p59.
- clone_dep therefore equals clone_ind for these arms, reported as "clone": 50,769 near orphans duplicated, about 2x near-decoy density.
- Removal: 19% of S1 dropped and the rival recomputed. p006's pool-side inputs are NOT recomputed (the 006 models are not in the kit), so this is unconfirmed and weak: p006 itself does not move (0.97443 -> 0.97443).

Paired diff (SE; all 5/5 folds, PASS):

| condition | p5 - p006 | p59 - p006 | p59 - p5 |
|---|---|---|---|
| normal | +0.00722 (0.00008) | +0.01014 (0.00012) | +0.00292 (0.00009) |
| clone | **+0.00883** (0.00011) | **+0.01246** (0.00013) | **+0.00363** (0.00009) |
| removal | +0.00723 (0.00013) | +0.01018 (0.00010) | +0.00294 (0.00011) |

- By country, p59 - p006:
  - normal US +0.00952 / India +0.01108;
  - clone US +0.01137 / India +0.01411.
- Decoy-weighted (S1 with near orphans x2.4), p59 - p006: normal +0.01387, clone +0.01812.
- **The gain grows when decoys are denser**, by about 23% for every pair of arms. p59 keeps its lead over p5 (+0.00363).
  - Absolute F0.5 under clone: p006 0.97124, p5 0.98007, p59 0.98370. p59 loses only 0.0009 to the extra decoys; p006 loses 0.0032.
- US false positives, normal -> clone:
  - p006 2,425 -> 5,099 (2,429 are clones);
  - p5 1,494 -> 2,890 (1,298 clones);
  - p59 1,043 -> 1,888 (789 clones).
  - p59 emits 3.1x fewer cloned decoys than p006.
- Guard caveat (measured): p5 and p59 raise the house-conflict share of emitted pairs (US 0.071 -> 0.081 / 0.084; India 0.161 -> 0.167 / 0.168) while cutting false positives by 38-57%. They recover true second-address matches. On test, a rise of that size is expected and is not by itself a decoy signal; compare with these train numbers.
- Script: `stage3.py`; log `research/r7/stage3.log`; `stage3.json`.

## 3. Build spec (hed)
- New side-car `src/er_feat6.py`: house-edit features for every candidate pair from norm `house` (S1 vs pool). rapidfuzz Levenshtein runs only where both are non-empty and differ; numeric difference only for all-digit houses.
- Add the features to stage 1 and stage 2, then rerun the 006 chain.
- Compute: features ~10 min per split, peak ~12 GB (98M pairs, two string columns; chunk by country for less). Retrain = the 006 cost.
- Do not add pool-pool support or coherence features (2.4).
- Follow-up idea (untested): an anchored S1-side count (strong candidates at the S1's exact house) as context for the small-edit flag. Decoy clusters cannot raise it.

## 4. Risks and interactions
- The house-edit features may overlap another lane's house features. A combined run must check that the gains add.
- France is unlabeled. The small-edit penalty transfers untested; test France small-edit pairs are 0.02-0.16 per S1 in the low bands.
- Transitive rescue through exact address twins is unsafe: name-mutated decoys copy a true record's address, typos included (Olanoari / Novinovinyla share "south joordan").
- The removal simulation changes little by design: the test excess is not missing S1 (2.2). clone_dep is the relevant stress test.
