## Leakage audit (07:00 IST)
How A/B were trained: split by S1 entity on the harness folds. half 0 = folds {0,1}, half 1 = folds {2,3,4}; data/folds.parquet is identical to the reproduced folds, and the ce_pairs half labels agree with it for every row. Model A trained only on pairs of 470k sampled half-0 S1 and scored only half-1 band pairs; model B the reverse. Checked on the real outputs (research/r16/leak.py): model A scored 1,804,676 pairs / 678,475 S1 with 0 S1 and 0 pair overlap with its own training set; model B scored 1,204,311 pairs / 450,958 S1, also 0 / 0. No model scored its own training S1, and the split was never by pair. The stack is also clean: fold i predictions use only the fold i CE (from a model trained on other folds) and a LightGBM fitted on folds != i.
Test data: the training notebook read only train_s1/train_pool (records dataset) plus ce_pairs (train gold + train candidates). Test records were used only for inference in the scoring notebook. No external data. Model: intfloat/multilingual-e5-small (MIT) downloaded from the HF hub.
Residual exposure on the pool side: 76.1% of scored train band pairs involve a pool record that appeared in the scoring model's training pairs, usually as a negative candidate of some other-half S1. Test pool records were never seen, so this is a possible train/test difference. How much it matters:
- CE AUC on pairs with a seen pool record is 0.905 / 0.903 (A/B; pos 0.08), vs 0.957 / 0.957 on unseen ones (pos 0.43). Exposure doesn't make the CE look better.
- Per-S1 paired F0.5 gain of r16_ce over 018 (research/r16/leak2.py): no band pool record seen, 342,024 S1: +0.00349 (per-fold 0.00333-0.00370, 5/5); mixed, 217,014 S1: +0.00359; all seen, 570,395 S1: +0.00065 (5/5); S1 with no band pairs, 1,077,388: 0. The gain is largest where there is no exposure, so exposure isn't inflating it.
- Masked variant (CE set to NaN for seen-pool pairs, research/r16/mask.py): +0.00085 vs 018, 5/5 PASS; full CE adds +0.00021 on top. Not a clean bound, because the NaN pattern is itself label-correlated. For information only.
Verdict: no in-sample leakage. The +0.00106 gain comes from out-of-fold CE scores, and the clean-subset analysis supports it.
