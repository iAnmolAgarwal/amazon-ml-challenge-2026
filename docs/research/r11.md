## 5. Risks and interactions
- T is a residual on 018: retrain it on whatever parent ships (t_final.py takes the parent name). If r12's generator
  features join the same band model, expect overlap; the side-cars in section 3 support that.
- The train OOF has route pairs for only the 10% sample; T excludes route pairs from its band, so the NaN-feature
  shift does not arise; route pairs keep their 018 probability.
- Stacking note: pr_* for a validation pair uses p018 of other S1 on the same pool, whose 018 fold model may have seen
  the validation pair's label. This is the second-order stacking path already accepted for feat4 (cp_*); a
  127-leaf, min_data 200 model cannot isolate one pool, and every per-fold gain is identical (0.00062-0.00064).
- The band stage-2 capacity retrain (b2.py) was stopped under CPU contention; the T-noP ablation (+0.00016) shows the
  old features still hold residual signal, which T already takes.
