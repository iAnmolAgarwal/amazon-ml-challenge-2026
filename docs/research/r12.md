What it is: a LightGBM correction boosted from logit(p018) (init_score), on pairs with 0.003 <= p018 <= 0.997
(train 3,067,030 pairs, 492,776 gold; test 2,808,384 pairs of which 2,015,622 US/India are rescored; France and
all pairs outside the band keep p018). Inputs: lp = logit(p018) clipped at 1e-6, india flag, is3 (pool id prefix
S3), pef (pool addr_norm empty), plus pair-local, label-free generator features computed from the raw records and
norm nums/house (no sibling, pool-context or S1-context information):
- gf.py (26): number-multiset diff (nA, nB, any +d in D={3,4,5,7,9,11,13,21}, any +1/+2, last-digit truncation,
  first-digit drop, delta, primary-house-changed), best name-token edit (distance, position end/start/middle,
  digit-for-letter, doubled letter, transposition, acronym letter change), name prefix drop/add, raw-string cues
  (raw/lower equality, upper case, <NULL>, #, PMB/PO BOX, 1/x fraction change, empty address).
- gf2.py (21): legal-form ids of S1 and pool (inc/llc/ltd/corp/co/lp/llp/pvt/pc/pllc/plc/public), counts, reorder,
  join/split, filler/honorific adds, formerly/dba/aka, web form, (ID:) tag, first/last token equality, address
  words only in S1 / only in pool, leading zero, house letter suffix, token counts.
- gf3.py (11): numeric operation code for the primary house and first changed secondary number (drop last, drop
  first, +D, -D, +-1/2, one digit, transposition, insertion, prefix, suffix, leading zeros), deltas, counts.
- gf4.py (18): core-name Levenshtein and ratio, typo/unknown token counts, edit-op counts (end substitution,
  vowel, doubled, digit, insert, delete), dropped-token position, acronym, native script flags, lengths.
- gf5.py (6): confusable characters (i/l, o/0, l/1, s/5, b/8 ...), one-word swap, share of S1 numbers kept,
  first/last number equal.   gf6.py (7, R_123456 only): street words equal/overlap/ratio, other-component overlap.

## Twins, local (Mac only, AWS suspended; scripts scratchpad/r12local/t0-t4.py; raw records + gold, M unless tagged)
Sample: 20% of exact twin groups (S1s in one country with the same lowercase alphanumeric name, chosen by a hash of
that name), restricted to groups that own at least one empty-address pool record: 13,882 groups, 108,608 S1,
23,361 empty-address gold records, mean group size seen by a record 18.7, chance top-1 (mean 1/n) 0.239. Peak RSS
1.34 GB. Question: does anything in raw records or gold structure tell which twin owns an empty-address record?
| signal (owner vs other twins) | groups where it varies | top-1 there | chance there |
|---|---|---|---|
| case pattern, accents, double spaces of the S1 name | 0% (twins never differ) | - | - |
| punctuation set of pool name = S1 name's | 14.6% | 0.259 | 0.144 |
| raw name exactly equal | 1.2% | 0.256 | 0.184 |
| last token (legal form spelling) equal | 2.3% | 0.239 | 0.141 |
| exact / lowercase name equal to one of the twin's other records | 21.6% / 26.7% | 0.167 / 0.182 | 0.163 / 0.176 |
| max similarity to the twin's other records (any / same source) | 97% | 0.231 / 0.212 | 0.232 / 0.233 |
| fewer same-source matches (source balance) | 92% | 0.261 | 0.218 |
| fewer matches in total | 95% | 0.234 | 0.224 |
| S1 address has unit / comma count | 48% / 73% | 0.136 / 0.181 | 0.136 / 0.178 |
- Only 19% of these records sit in a group whose twins differ at all in raw spelling. Twins differ only in punctuation
  (the alphanumeric string is identical by definition, and case/accents/spacing never differ), and the pool record
  inherits the owner's punctuation more often than chance.
- Combined conditional logit over all signals (fit on half the groups, scored on the other half): top-1 0.317 vs chance
  0.239; log-likelihood -1.973 vs -2.044 per record (0.07 nats). Calibrated: posterior bins 0.6-0.73 / 0.73-0.9 /
  >0.9 hold the owner 0.64 / 0.73 / 0.88 of the time. Only 827 of 23,361 records (3.5%) reach a posterior of 0.73,
  about where emitting to a twin with t=4 breaks even.
- F0.5 value (D, simulation on the sample, scaled to the full train, vs a baseline that emits none of these empty
  records): emit the top twin when q >= 0.5: -0.00074; 0.6: -0.00012; 0.7: +0.00005; 0.8: +0.00006 (US +0.00005,
  India +0.00007); 0.9: +0.00005. It is an upper bound: 018 already emits some of these records, and 018's S1-side
  competition features already carry part of the count signal (e9: S1-side source counts added +0.00001 on AWS).
- Two empty records with identical raw names in a group always share the owner (50 of 50 pairs), but only 50 of
  28,189 same-group pairs are identical; all other pairs share the owner at chance (0.052-0.061 vs 0.056-0.059).
Verdict: the twins are exchangeable up to punctuation inheritance and a weak source-balance prior. Best local
signal: top-1 0.317 vs 0.239, F0.5 value <= +0.00006 (D). Not worth building; the +0.003-0.005 twin oracle is
not reachable from raw records and gold. What stays open: a
punctuation-signature feature (pool punctuation set = S1 punctuation set) is new to every feature set and pair-local;
it could be added to gf2 when AWS is back (expected size small, G).
